# Privacy Policy for VibeSync All in ONE PDF Suite

**Effective Date:** October 5, 2026  
**Last Updated:** October 5, 2026  
**Application:** VibeSync All in ONE PDF Suite  
**Developer Contact:** vibesyncrotechnologies@gmail.com

## 1. Privacy Commitment

VibeSync All in ONE PDF Suite ("VibeSync", "the App", "we", "us", or "our") is
designed as an on-device document workstation.

VibeSync does not intentionally upload or transmit the contents of PDFs,
documents, signatures, annotations, or scanned pages to VibeSync-operated cloud
storage. Core PDF processing is intended to take place locally on the device.

When a user explicitly shares a document with another application or service,
the receiving application or service controls its own handling of that document.

## 2. Local Document Processing

Core document operations include viewing, editing, signing, splitting, merging,
watermarking, conversion, extraction, encryption, and document scanning.

These operations are designed to execute locally using Android platform
components and bundled/installed third-party libraries.

## 3. Storage and Permissions

VibeSync may request Android permissions needed for local document discovery or
for user-selected media/document workflows. Permission availability and names
vary by Android version.

Where Android system pickers are used, the user selects the files or media made
available to the App.

The App may use network access for third-party platform services such as
advertising. Network access for those services does not mean that VibeSync
uploads PDF contents to those services.

## 4. Advertising and Third-Party Services

VibeSync uses Google Mobile Ads (AdMob) to support the application.

Third-party SDKs and services may process information such as advertising
identifiers, diagnostics, approximate location, or other data as described by
their own policies and configuration.

Google's applicable privacy information is available at:

https://policies.google.com/privacy

VibeSync does not control third-party data practices. Users should review the
current policies of Google and any other third-party service integrated into the
App.

## 5. Signatures and Local Security

Digital signatures and related security data are designed to remain within the
device's protected application environment and Android security facilities.

VibeSync does not intentionally transmit stored signature data to VibeSync
servers.

## 6. Data Retention and Deletion

Because VibeSync does not provide VibeSync-operated cloud storage for user PDFs,
there is no VibeSync cloud document account from which users must request
document deletion.

Users can remove local application data through Android system settings or
uninstall the application. Original documents stored elsewhere on the device
remain under the user's control unless the user chooses to modify or delete
them.

## 7. Children's Privacy

VibeSync is not directed to children and does not knowingly request personal
information from children.

## 8. Security

Release builds use standard Android application security practices, including
code shrinking/obfuscation where configured, protected application storage,
and Android cryptographic facilities for protected local data.

No security measure can guarantee absolute security. Users should keep Android
and the VibeSync application updated and use appropriate device security.

## 9. Changes to This Policy

This Privacy Policy may be updated when the App, third-party services, or legal
requirements change. The current version will be published in this public
repository with an updated date.
